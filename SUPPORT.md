# Support

This is a personal site maintained on a best-effort basis. There is no paid
support channel or guaranteed response time.

Before opening an issue:

1. Use Node 24.19.0 and npm 11.19.0.
2. Run `npm run help` and the narrowest relevant check.
3. Search existing issues and the operations runbook.
4. Confirm the problem is reproducible without private provider data.

Use a GitHub issue for a reproducible bug or focused documentation problem.
Include expected and actual behavior, a minimal reproduction, runtime versions,
and sanitized command output. Do not post credentials, environment values,
subscriber details, email content, private URLs, provider payloads, or local
filesystem paths.

Questions about adapting a public fork should first consult `README.md`,
`NOTICE`, `docs/asset-rights.md`, and `docs/contributor-tooling.md`. Requests for
personal-site customization, deployment administration, or third-party
provider account support may be closed as out of scope.

Report suspected vulnerabilities privately according to `SECURITY.md`, never
through a public support issue.
